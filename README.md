# SmartWorkout
IAWeeksProject

Smart Workout 

Smart Workout è una semplice applicazione web sviluppata con Streamlit che aiuta a creare allenamenti personalizzati in base agli attrezzi disponibili.
L’idea è quella di simulare un piccolo coach digitale che suggerisce esercizi, tiene traccia delle serie completate e gestisce i tempi di recupero tra una serie e l’altra.
L’app permette di:

- generare un allenamento in base agli attrezzi disponibili
- utilizzare una chat semplice per interagire con il coach
- visualizzare gli esercizi sotto forma di schede
- tenere traccia delle serie completate
- usare un timer di recupero tra una serie e l’altra
- visualizzare una barra di avanzamento dell’allenamento
- ricevere un messaggio di completamento workout
